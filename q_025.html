Question 25 / 201

You need to run a business-critical workload on a fixed set of Compute Engine instances for several months. The workload is stable with the exact amount of resources allocated to it. You want to lower the costs for this workload without any performance implications. What should you do?

  • A. Purchase Committed Use Discounts.
  • B. Migrate the instances to a Managed Instance Group.
  • C. Convert the instances to preemptible virtual machines.
  • D. Create an Unmanaged Instance Group for the instances used to run the workload.
Show Suggested Answer
Suggested Answer: A 
Odpowiedź: A.

Wyjaśnienie:
Poprawna odpowiedź to A. Committed Use Discounts (CUDs) to mechanizm, w którym użytkownik zobowiązuje się do zakupu określonej ilości zasobów obliczeniowych (vCPU, RAM) przez określony czas (rok lub trzy lata). W zamian otrzymuje znaczące obniżki kosztów (nawet do 57-70%). Jest to rozwiązanie dedykowane dla obciążeń typu "steady-state" (stałych, przewidywalnych), ponieważ pozwala na znaczną optymalizację budżetu bez konieczności zmiany architektury aplikacji czy ryzyka przerwania działania instancji.

Dlaczego inne odpowiedzi są błędne:
B. Przejście na Managed Instance Groups (MIGs) zwiększa łatwość zarządzania (np. dzięki auto-healing i auto-scaling), ale samo w sobie nie zmniejsza jednostkowego kosztu instancji. Aby realnie obniżyć koszty przy użyciu MIGs, należałoby również zastosować Committed Use Discounts (CUDs) dla instancji w grupie.
C. Preemptible VMs (obecnie Spot VMs) są bardzo tanie, ale GCP może je w każdej chwili wyłączyć z 30-sekundowym wyprzedzeniem. Użycie ich w "business-critical workload" jest skrajnie nieodpowiedzialne, gdyż może doprowadzić do nieplanowanych przestojów aplikacji.
D. Unmanaged Instance Groups wymagają ręcznego zarządzania każdą instancją z osobna, co jest nieefektywne (wysoki poziom "Toil"). Nie oferują one żadnych mechanizmów optymalizacji kosztowej, a wręcz przeciwnie – generują dodatkowe koszty operacyjne poprzez konieczność poświęcenia czasu inżynierów na ich obsługę.
