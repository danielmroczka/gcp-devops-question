Stackdriver

You support a trading application written in Python and hosted on App Engine flexible environment. You want to customize the error information being sent to Stackdriver Error Reporting. What should you do?

  • A. Install the Stackdriver Error Reporting library for Python, and then run your code on a Compute Engine VM.
  • B. Install the Stackdriver Error Reporting library for Python, and then run your code on Google Kubernetes Engine.
  • C. Install the Stackdriver Error Reporting library for Python, and then run your code on App Engine flexible environment.
  • D. Use the Stackdriver Error Reporting API to write errors from your application to ReportedErrorEvent, and then generate log entries with properly formatted error messages in Stackdriver Logging.
Show Suggested Answer
Suggested Answer: D 
Odpowiedź: D.

Wyjaśnienie:
Poprawna odpowiedź to D. Aby mieć pełną kontrolę nad strukturą i formatowaniem błędów wysyłanych do Error Reporting, należy użyć dedykowanego API (ReportedErrorEvent). Pozwala to na precyzyjne definiowanie kontekstu błędu (np. wersja usługi, nazwa funkcji, użytkownik), co znacznie ułatwia debugowanie w środowiskach takich jak App Engine Flexible, GKE czy GCE.

Analiza błędnych odpowiedzi:
- A, B, C: Same biblioteki (klienty) działają w różnych środowiskach, ale "personalizacja" (customizing) informacji o błędzie w pełnym zakresie, zgodnie z dokumentacją GCP, odbywa się przez dedykowane API, które zapewnia spójność bez względu na środowisko uruchomieniowe.

Przydatne linki:
- https://cloud.google.com/error-reporting/docs/reference/rest/v1beta1/projects.events/report
