Question 101 / 201

Logging

You are managing an application that runs in Compute Engine. The application uses a custom HTTP server to expose an API that is accessed by other applications through an internal TCP/UDP load balancer. A firewall rule allows access to the API port from 0.0.0.0/0. You need to configure Cloud Logging to log each IP address that accesses the API by using the fewest number of steps.

What should you do first?

  • A. Enable Packet Mirroring on the VPC.
  • B. Install the Ops Agent on the Compute Engine instances.
  • C. Enable logging on the firewall rule.
  • D. Enable VPC Flow Logs on the subnet.
Show Suggested Answer
Suggested Answer: D 
Odpowiedź: D

Wyjaśnienie:
Potrzebujesz logować każdy adres IP, który uzyskuje dostęp do API w Compute Engine (przez wewnętrzny load balancer).

Dlaczego D jest poprawną odpowiedzią:
- VPC Flow Logs: Rejestrują informacje o przepływach sieciowych wewnątrz sieci VPC (w tym źródłowe i docelowe adresy IP, porty, protokoły). Jest to najprostszy ("fewest number of steps") sposób na uzyskanie informacji o ruchu sieciowym docierającym do instancji, bez konieczności instalacji agentów czy zmian w aplikacji.

Wyjaśnienie niepoprawnych odpowiedzi:
- A: Packet Mirroring pozwala na głęboką inspekcję ruchu, ale jest to skomplikowane i kosztowne rozwiązanie, zazwyczaj używane do celów diagnostycznych lub bezpieczeństwa, a nie tylko do logowania adresów IP.
- B: Ops Agent może logować dane z aplikacji, ale wymaga instalacji i konfiguracji agenta na każdej instancji. VPC Flow Logs są zarządzane na poziomie infrastruktury (subnety), więc wymagają znacznie mniej "kroków".
- C: Logowanie na regule firewalla (Firewall Rules Logging) rejestruje trafienia na konkretną regułę, ale jest zazwyczaj stosowane do celów bezpieczeństwa i debugowania konkretnych blokad, a nie do logowania całego ruchu API (VPC Flow Logs są bardziej dedykowane do tego celu).

Więcej informacji:
- Google Cloud: VPC Flow Logs
- Google Cloud: Firewall Rules Logging

Analiza i Podsumowanie Dyskusji (AI)

Jeśli potrzebujesz logowania ruchu sieciowego wewnątrz VPC bez modyfikacji aplikacji, zawsze myśl o VPC Flow Logs.

💡 Wskazówki i Triki (Exam Tips)

  • "Fewest steps" (Najmniej kroków): GCP stawia na usługi sieciowe (managed). Zawsze wybieraj konfigurację na poziomie VPC/Subnetu, jeśli to możliwe, zamiast instalacji agentów.
