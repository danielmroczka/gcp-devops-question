Question 196 / 201

GKE Kubernetes Logging

You are deploying a new application on Google Kubernetes Engine (GKE) that processes personally identifiable information (PII). You need to configure Cloud Logging to collect logs from your application while ensuring that sensitive user information is not exposed.

What should you do?

  • A. Implement log sampling to reduce the volume of logs collected.
  • B. Configure Cloud Data Loss Prevention to scan logs in real-time and redact PII before it's stored in Cloud Logging.
  • C. Disable Cloud Logging for the application to prevent sensitive data from being logged.
  • D. Store all logs in an encrypted Cloud Storage bucket with restricted access.
Show Suggested Answer
Suggested Answer: B 
Odpowiedź: B

Wyjaśnienie:
Cloud Data Loss Prevention (DLP), teraz część Sensitive Data Protection, jest natywną usługą Google Cloud zaprojektowaną do automatycznego wykrywania, klasyfikowania i redakcji (maskowania) wrażliwych danych (PII). Konfiguracja DLP z Cloud Logging pozwala na automatyczne oczyszczanie logów z wrażliwych informacji przed ich trwałym zapisaniem, co jest kluczowe dla spełnienia wymagań regulacyjnych (np. RODO/GDPR) i bezpieczeństwa.

Wyjaśnienie niepoprawnych odpowiedzi:
- Opcja A: Log sampling zmniejsza ilość danych, ale nie usuwa PII z logów, które zostaną zapisane.
- Opcja C: Wyłączenie logowania utrudnia debugowanie i audyt aplikacji, co jest niedopuszczalne w systemach produkcyjnych.
- Opcja D: Nawet jeśli bucket jest zaszyfrowany, PII nadal znajduje się w logach w postaci jawnej (cleartext), co nie rozwiązuje problemu ekspozycji danych dla użytkowników z uprawnieniami do odczytu logów.

Więcej informacji:
- Sensitive Data Protection: Redacting sensitive data in Cloud Logging

Analiza i Podsumowanie Dyskusji (AI)

W pytaniach dotyczących PII i bezpieczeństwa w GCP, zawsze szukaj natywnej usługi ochrony danych (Sensitive Data Protection / DLP).

💡 Wskazówki i Triki (Exam Tips)

  • PII + Logging = Sensitive Data Protection (DLP).
  • Redakcja logów powinna odbywać się przed ich trwałym zapisem.
