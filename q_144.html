Question 144 / 201

You have an application that runs on Cloud Run. You want to use live production traffic to test a new version of the application, while you let the quality assurance team perform manual testing. You want to limit the potential impact of any issues while testing the new version, and you must be able to roll back to a previous version of the application if needed.

How should you deploy the new version? (Choose two.)

  • A. Deploy the application as a new Cloud Run service.
  • B. Deploy a new Cloud Run revision with a tag and use the --no-traffic option.
  • C. Deploy a new Cloud Run revision without a tag and use the --no-traffic option.
  • D. Deploy the new application version and use the --no-traffic option. Route production traffic to the revision's URL.
  • E. Deploy the new application version, and split traffic to the new version.
Show Suggested Answer
Suggested Answer: B, C 
Odpowiedź: B, C

Wyjaśnienie:
W Cloud Run, aby przetestować nową wersję bez narażania użytkowników:
1. Używamy --no-traffic: Zapobiega to automatycznemu kierowaniu ruchu produkcyjnego do nowej wersji.
2. Używamy tagów: Tagi w Cloud Run pozwalają na stworzenie dedykowanego, stabilnego adresu URL dla nowej wersji (revision), dzięki czemu zespół QA może przetestować wersję przed jej publicznym udostępnieniem.

Wyjaśnienie niepoprawnych odpowiedzi:
- Opcja A: Tworzenie nowego serwisu dla każdej wersji jest nieefektywne i utrudnia zarządzanie ruchem oraz rollbacki.
- Opcja D: Kierowanie ruchu produkcyjnego do URL rewizji (zamiast użycia podziału ruchu) jest ryzykowne i nie zapewnia izolacji potrzebnej do testów QA.
- Opcja E: Splitting traffic (podział ruchu) automatycznie kieruje część ruchu użytkowników na nową wersję, co jest niebezpieczne, jeśli nie została ona jeszcze zweryfikowana przez QA.

Analiza i Podsumowanie Dyskusji (AI)

Kluczem w Cloud Run jest użycie tags do testowania rewizji bez przerywania ruchu głównego.

💡 Wskazówki i Triki (Exam Tips)

  • --no-traffic: Zawsze używaj tego podczas wdrażania nowej rewizji, jeśli nie chcesz, aby od razu odbierała ruch.
  • Tags: Pozwalają na testowanie konkretnej rewizji przez dedykowany URL.
