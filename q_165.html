Question 165 / 201

Monitoring SLO

You are monitoring a service that uses n2-standard-2 Compute Engine instances that serve large files. Users have reported that downloads are slow. Your Cloud Monitoring dashboard shows that your VMs are running at peak network throughput. You want to improve the network throughput performance. What should you do?

  • A. Add additional network interface controllers (NICs) to your VMs.
  • B. Deploy a Cloud NAT gateway and attach the gateway to the subnet of the VMs.
  • C. Change the machine type for your VMs to n2-standard-8.
  • D. Deploy the Ops Agent to export additional monitoring metrics.
Show Suggested Answer
Suggested Answer: C 
Odpowiedź: C

Wyjaśnienie:
W Google Cloud przepustowość sieci (network throughput) dla instancji Compute Engine jest bezpośrednio powiązana z liczbą vCPU w danym typie maszyny.
1. Zależność vCPU -> Przepustowość: Większe maszyny (posiadające więcej vCPU) mają wyższe limity przepustowości sieciowej. Zmiana z n2-standard-2 (2 vCPU) na n2-standard-8 (8 vCPU) znacząco zwiększy maksymalną przepustowość dostępną dla instancji, co rozwiąże problem "peak network throughput" i przyspieszy pobieranie plików.

Wyjaśnienie niepoprawnych odpowiedzi:
- Opcja A: W GCP, dla większości typów maszyn, dodawanie dodatkowych interfejsów NIC nie zwiększa ogólnej przepustowości sieciowej instancji, która jest limitowana przez jej typ (vCPU).
- Opcja B: Cloud NAT służy do umożliwienia instancjom w prywatnych podsieciach dostępu do internetu, a nie do zwiększania przepustowości sieciowej samych maszyn.
- Opcja D: Ops Agent służy do zbierania metryk, nie wpływa w żaden sposób na wydajność sieciową instancji.

Więcej informacji:
- Google Cloud: Compute Engine Network Bandwidth

Analiza i Podsumowanie Dyskusji (AI)

Jeśli widzisz problem z "network throughput" w Compute Engine, pierwszą rzeczą do sprawdzenia w dokumentacji jest limit przepustowości dla typu maszyny (zależy on od liczby vCPU).

💡 Wskazówki i Triki (Exam Tips)

  • vCPU = Network Bandwidth: W Compute Engine większa liczba vCPU to niemal zawsze większa przepustowość sieciowa.
