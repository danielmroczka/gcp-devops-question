GCP DevOps

Which GCP configuration enables Data Access audit logs for Cloud Storage and BigQuery and exports them to a Cloud Storage bucket with 30 day retention?

  • A. Create a sink to Pub/Sub and set 30 day retention in Pub/Sub
  • B. Enable only Admin Activity logs and export to Cloud Storage
  • C. Enable Data Access logs and a Log Router sink to Cloud Storage with a 30 day lifecycle delete rule
  • D. Use Cloud Logging log buckets with 30 day retention and no export
Show Suggested Answer
Suggested Answer: C 
Odpowiedź: C

Wyjaśnienie:
Poprawna odpowiedź to C. 
- Logi Data Access nie są włączone domyślnie (z wyjątkiem Admin Activity), więc trzeba je jawnie skonfigurować w polityce IAM lub Logging.
- Log Router (sink) służy do eksportowania logów do Cloud Storage.
- Aby zrealizować wymóg 30-dniowej retencji w Cloud Storage, należy skonfigurować regułę "lifecycle delete" (Object Lifecycle Management) na samym buckecie GCS.

Wyjaśnienie błędnych odpowiedzi:
- A: Pub/Sub nie służy do trwałego przechowywania logów z retencją 30 dni w ten sposób.
- B: Admin Activity są włączone domyślnie; pytanie wymaga Data Access logs.
- D: Log buckets w Cloud Logging mogą mieć retencję, ale wymaganie mówi o eksporcie do "Cloud Storage bucket".

Dlaczego C jest poprawne?

Kluczowe kroki: włączenie odpowiednich logów + eksport przez Log Router + retencja w GCS.

Dlaczego pozostałe są błędne?

  • A, B, D: Nie spełniają wymagań funkcjonalnych lub konfiguracyjnych.
