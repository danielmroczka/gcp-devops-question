Question 272 / 284

Your application logs are captured in Cloud Logging and routed to a Cloud Logging bucket. You want a way to quickly provide access to the logs for teams to run SQL queries. What should you do? (Choose two)

  • A. Copy the logs to a BigQuery dataset and provide access to team members.
  • B. Upgrade the logging bucket for Log Analytics support.
  • C. Export logs to CSV on Cloud Storage, and use federated queries from BigQuery.
  • D. Create a linked dataset from BigQuery to a Log Analytics bucket.
  • E. Use Logs Explorer to review logs in Cloud Logging.
Show Suggested Answer
Suggested Answer: B, D 
Odpowiedź: B, D

Wyjaśnienie:
Log Analytics w Cloud Logging pozwala na bezpośrednie wykonywanie zapytań SQL na logach przechowywanych w tzw. bucketach (Log Analytics buckets). Aby to osiągnąć, należy włączyć obsługę Log Analytics w bucketcie (B), a następnie można stworzyć powiązany dataset w BigQuery (linked dataset) (D), aby umożliwić zaawansowane zapytania SQL bezpośrednio na logach.

Wyjaśnienie błędnych odpowiedzi:
- A, C: Eksportowanie logów jest starszym podejściem; Log Analytics pozwala na znacznie szybszy wgląd bez potrzeby kopiowania danych.
- E: Logs Explorer służy do przeglądania logów, a nie do zaawansowanych zapytań SQL przez zespoły.

Analiza i Podsumowanie Dyskusji (AI)

SQL on Cloud Logging = Log Analytics buckets + linked BQ dataset.

💡 Wskazówki i Triki (Exam Tips)

  • Fast SQL on logs = Log Analytics.
