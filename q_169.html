Question 169 / 201

Your company runs services on Google Cloud. Each team runs their applications in a dedicated project. New teams and projects are created regularly. Your security team requires that all logs are processed by a security information and event management (SIEM) system. The SIEM ingests logs by using Pub/Sub. You must ensure that all existing and future logs are scanned by the SIEM.

What should you do?

  • A. Create an organization-level aggregated sink with a siem log bucket as the destination. Set an inclusion filter to include all logs.
  • B. Create a folder-level aggregated sink with a siem Pub/Sub topic as the destination. Set an inclusion filter to include all logs. Repeat for each folder.
  • C. Create an organization-level aggregated sink with a siem Pub/Sub topic as the destination. Set an inclusion filter to include all logs.
  • D. Create a project-level logging sink with a siem Pub/Sub topic as the destination. Set an inclusion filter to include all logs. Repeat for each project.
Show Suggested Answer
Suggested Answer: C 
Odpowiedź: C

Wyjaśnienie:
1. Wymagania: Musisz zapewnić, że logi ze wszystkich obecnych i przyszłych projektów są skanowane przez SIEM przez Pub/Sub.
2. Rozwiązanie: Organizacyjne (organization-level) agregowane (aggregated) sinki automatycznie obejmują wszystkie projekty i foldery wewnątrz organizacji, nawet te tworzone w przyszłości. Użycie Pub/Sub jako celu (destination) jest bezpośrednio wymagane przez SIEM w tym scenariuszu.

Wyjaśnienie niepoprawnych odpowiedzi:
- Opcja A: Log bucket jest magazynem logów (Cloud Logging storage), a nie potokiem danych (jak Pub/Sub), więc SIEM nie będzie mógł ich odczytać w sposób ciągły zgodnie z wymaganiami.
- Opcja B: Folder-level sinki działają, ale wymagają ręcznego powtarzania konfiguracji dla każdego folderu, co jest nieefektywne (zwiększa 'toil') i narusza zasadę automatyzacji. Organizacyjny sink załatwia sprawę raz dla całej organizacji.
- Opcja D: Projekt-level sinki wymagają ręcznej konfiguracji dla każdego nowego projektu, co przy częstym tworzeniu nowych projektów prowadzi do błędu ludzkiego i pominięcia logów.

Więcej informacji:
- Google Cloud: Aggregated Sinks
- Google Cloud: Exporting logs to Pub/Sub

Analiza i Podsumowanie Dyskusji (AI)

Kluczem do tego typu pytań jest słowo "all current and future" (wszystkie obecne i przyszłe). Zawsze szukaj rozwiązań na poziomie organizacji (Organization-level), aby uniknąć konieczności ręcznego zarządzania (toil).

💡 Wskazówki i Triki (Exam Tips)

  • Aggregation = Org/Folder Level: Jeśli zadanie mówi o wszystkich projektach w organizacji, użyj "Aggregated Sink".
  • Integration = Pub/Sub: Integracje z zewnętrznymi SIEM w GCP prawie zawsze wykorzystują Pub/Sub jako pośrednika.
