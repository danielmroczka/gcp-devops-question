Question 123 / 201

Monitoring

You are currently planning how to display Cloud Monitoring metrics for your organization's Google Cloud projects. Your organization has three folders and six projects:You want to configure Cloud Monitoring dashboards to only display metrics from the projects within one folder. You need to ensure that the dashboards do not display metrics from projects in the other folders. You want to follow Google-recommended practices. What should you do?

  • A. Create a single new scoping project.
  • B. Create new scoping projects for each folder.
  • C. Use the current app-one-prod project as the scoping project.
  • D. Use the current app-one-dev, app-one-staging, and app-one-prod projects as the scoping project for each folder.
Show Suggested Answer
Suggested Answer: B 
Odpowiedź: B

Wyjaśnienie:
Aby wyświetlać metryki Cloud Monitoring z projektów w określonym folderze i wykluczyć inne foldery, należy utworzyć projekt zakresu (scoping project) dla każdego folderu.
Cloud Monitoring pozwala na grupowanie projektów w "Multi-project observability". Projekt zakresu (scoping project) definiuje zakres danych, które są widoczne w pulpitach nawigacyjnych.
Tworząc osobny projekt zakresu dla każdego folderu, uzyskujesz logiczną separację danych monitorowania odpowiadającą strukturze folderów w organizacji.

Wyjaśnienie niepoprawnych odpowiedzi:
- Opcja A: Jeden nowy projekt zakresu dla całej organizacji wyświetliłby metryki ze wszystkich projektów, nie spełniając wymagania ograniczenia do jednego folderu.
- Opcja C: Wykorzystanie istniejącego projektu produkcyjnego jako projektu zakresu jest ryzykowne (bezpieczeństwo, limity) i nie rozwiązuje problemu separacji według folderów.
- Opcja D: Używanie wielu projektów jako projektów zakresu dla każdego folderu jest niejasne i niezgodne z modelem "jeden projekt zakresu na grupę zasobów" (Multi-project scoping).

Więcej informacji:
- Google Cloud: Multi-project metrics scoping

Analiza i Podsumowanie Dyskusji (AI)

W pytaniach o Cloud Monitoring, kluczem jest zrozumienie pojęcia Scoping Project. Projekt ten działa jako "agregator" metryk z innych projektów.

💡 Wskazówki i Triki (Exam Tips)

  • Multi-project: Jeśli chcesz patrzeć na metryki z wielu projektów w jednym pulpicie, potrzebujesz scoping project.
  • Struktura: Scoping project jest logicznym kontenerem dla widoczności metryk. Jeśli masz strukturę folderów w organizacji, najczystszą architekturą jest dopasowanie projektów zakresu do tej struktury (np. 1 scoping project na folder/środowisko).
