Question 275 / 284

You need to create a development, UAT, and production environment for a business application. You want to keep these environments as identical as possible, while following Google-recommended practices. What should you do?

  • A. Create the production environment using the Google Cloud console. Run Cloud Asset Inventory, list the resources in the production environment, and recreate the resources by using the Google Cloud console.
  • B. Create the production environment using the Google Cloud console. Run a scan with the Security Command Center, list the resources in the production environment, and recreate the resources by using the gcloud CLI.
  • C. Create a Terraform configuration to define your environment. Use Terraform to deploy identical environments for development, UAT, and production.
  • D. Create bash shell scripts to create your environment, and rerun the scripts as required.
Show Suggested Answer
Suggested Answer: C 
Odpowiedź: C

Wyjaśnienie:
Terraform to standardowe, deklaratywne narzędzie do Infrastructure as Code (IaC) w GCP. Użycie Terraform do definiowania zasobów zapewnia, że wszystkie środowiska są budowane z tego samego kodu, co gwarantuje ich spójność (identical), powtarzalność i łatwość zarządzania zmianami w przeciwieństwie do ręcznego klikania w konsoli czy pisania skryptów shellowych.

Wyjaśnienie błędnych odpowiedzi:
- A, B: Ręczne tworzenie zasobów przez konsolę jest podatne na błędy i nie gwarantuje spójności.
- D: Skrypty bash są trudne w utrzymaniu i nie oferują zaawansowanego zarządzania stanem infrastruktury, co oferuje Terraform.

Analiza i Podsumowanie Dyskusji (AI)

Identical environments = IaC (Terraform).

💡 Wskazówki i Triki (Exam Tips)

  • Infrastructure consistency = Terraform.
