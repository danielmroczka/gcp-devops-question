Question 86 / 201

Your organization wants to collect system logs that will be used to generate dashboards in Cloud Operations for their Google Cloud project. You need to configure all current and future Compute Engine instances to collect the system logs, and you must ensure that the Ops Agent remains up to date.

What should you do?

  • A. Use the gcloud CLI to install the Ops Agent on each VM listed in the Cloud Asset Inventory,
  • B. Select all VMs with an Agent status of Not detected on the Cloud Operations VMs dashboard. Then select Install agents.
  • C. Use the gcloud CLI to create an Agent Policy.
  • D. Install the Ops Agent on the Compute Engine image by using a startup script
Show Suggested Answer
Suggested Answer: C 
Odpowiedź: C

Wyjaśnienie:
Efektywne zarządzanie agentami w dużej skali wymaga podejścia zautomatyzowanego, które nie tylko instaluje oprogramowanie, ale także utrzymuje je w aktualnym stanie na wszystkich (również nowych) instancjach.

- Opcja C (Poprawna): Agent Policy w GCP (realizowane przez Google Cloud OS Config) to rozwiązanie klasy enterprise do zarządzania agentami. Pozwala na zdefiniowanie polityki, która jest automatycznie egzekwowana dla instancji spełniających określone kryteria (np. etykiety). Dzięki temu nowe instancje automatycznie otrzymają agenta, a istniejące będą aktualizowane.

Wyjaśnienie niepoprawnych odpowiedzi:
- Opcja A: Ręczne uruchamianie skryptów przez gcloud CLI dla każdej VM jest rozwiązaniem typu "manual toiling", nie skaluje się i nie zapewnia automatycznego dołączania agenta do nowo tworzonych maszyn.
- Opcja B: Konsola Cloud Operations pozwala na ręczną instalację agentów na wybranych maszynach, ale jest to proces reaktywny i manualny – nie zapewnia automatycznego utrzymania (aktualizacji) dla nowych maszyn.
- Opcja D: Skrypty startowe (`startup scripts`) były popularne w przeszłości, ale są trudne w zarządzaniu przy dużej liczbie maszyn. Wymagają przebudowy obrazów lub ręcznego zarządzania skryptami przy każdej aktualizacji agenta, co zwiększa ryzyko błędów i nakład pracy (toil).

Analiza i Podsumowanie Dyskusji (AI)

W pytaniach o zarządzanie oprogramowaniem na wielu VM-ach w GCP, zawsze szukaj rozwiązań deklaratywnych (Agent Policy/OS Config) zamiast skryptów lub ręcznych działań.

💡 Wskazówki i Triki (Exam Tips)

  • Unikaj "Toilu": Jeśli proces wymaga ręcznego klikania lub uruchamiania skryptów dla każdej maszyny, to w egzaminie DevOps Professional jest to niemal zawsze błędna odpowiedź.
  • Skalowalność: Pytanie o "obecne i przyszłe" instancje to kluczowa wskazówka, że szukamy rozwiązania zautomatyzowanego, które działa na poziomie całego projektu/floty (fleet management).
