Question 107 / 201

Your application's performance in Google Cloud has degraded since the last release. You suspect that downstream dependencies might be causing some requests to take longer to complete. You need to investigate the issue with your application to determine the cause.

What should you do?

  • A. Configure Error Reporting in your application.
  • B. Configure Google Cloud Managed Service for Prometheus in your application.
  • C. Configure Cloud Profiler in your application.
  • D. Configure Cloud Trace in your application.
Show Suggested Answer
Suggested Answer: D 
Odpowiedź: D

Wyjaśnienie:
- Cloud Trace to usługa służąca do śledzenia zapytań (distributed tracing) w systemach rozproszonych. Pozwala ona na identyfikację wąskich gardeł (latency) poprzez wizualizację czasu, jaki zapytania spędzają w poszczególnych usługach lub zależnościach (downstream dependencies). Jest to narzędzie idealne do diagnozowania sytuacji, w której ogólna wydajność aplikacji spada z powodu opóźnień w zewnętrznych serwisach.

Wyjaśnienie niepoprawnych odpowiedzi:
- Opcja A (Error Reporting): Służy do monitorowania i powiadamiania o błędach aplikacji (wyjątkach), a nie do badania opóźnień (latency).
- Opcja B (Managed Service for Prometheus): Służy do zbierania metryk systemowych i aplikacyjnych (czasy odpowiedzi, wykorzystanie CPU/RAM), co pozwala zauważyć, że wydajność spadła, ale nie pozwala tak łatwo "wejść" w konkretne zapytanie i zobaczyć, który downstream serwis powoduje opóźnienie, jak robi to Trace.
- Opcja C (Cloud Profiler): Służy do analizy wydajności CPU i pamięci wewnątrz samego kodu aplikacji (np. gdzie kod zużywa najwięcej zasobów), a nie do badania opóźnień w komunikacji sieciowej między serwisami.

Analiza i Podsumowanie Dyskusji (AI)

Jeśli problemem jest latencja w systemach rozproszonych (np. komunikacja między mikrousługami), odpowiedź jest zawsze jedna: Cloud Trace.

💡 Wskazówki i Triki (Exam Tips)

  • Latency -> Cloud Trace
  • Performance bottlenecks in code -> Cloud Profiler
  • Metrics/Alerting -> Cloud Monitoring/Prometheus
  • Application Errors -> Error Reporting
