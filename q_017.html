Question 17 / 201

GKE Kubernetes

You support an e-commerce application that runs on a large Google Kubernetes Engine (GKE) cluster deployed on-premises and on Google Cloud Platform. The application consists of microservices that run in containers. You want to identify containers that are using the most CPU and memory. What should you do?

  • A. Use Stackdriver Kubernetes Engine Monitoring.
  • B. Use Prometheus to collect and aggregate logs per container, and then analyze the results in Grafana.
  • C. Use the Stackdriver Monitoring API to create custom metrics, and then organize your containers using groups.
  • D. Use Stackdriver Logging to export application logs to BigQuery, aggregate logs per container, and then analyze CPU and memory consumption.
Show Suggested Answer
Suggested Answer: A 
Odpowiedź: A.

Wyjaśnienie:
Stackdriver Kubernetes Engine Monitoring (obecnie w pełni zintegrowane w ramach Google Cloud Operations Suite / Cloud Monitoring) to natywne rozwiązanie GCP do monitorowania klastrów GKE. Zapewnia ono głęboką widoczność wewnątrz klastra, umożliwiając filtrowanie i sortowanie metryk (takich jak użycie CPU i pamięci) bezpośrednio na poziomie konkretnych kontenerów (podów). Jest to najbardziej "bezobsługowy" i efektywny sposób, ponieważ nie wymaga instalacji zewnętrznych narzędzi (jak Prometheus) ani budowania skomplikowanych rurociągów logów.

B. Prometheus to świetne narzędzie, ale wymaga "utrzymania" (patchowanie, skalowanie, zarządzanie pamięcią serwera Prometheus), co w pytaniu o "najbardziej efektywne" rozwiązanie na GCP jest gorszą opcją niż natywna usługa.
C. Ręczne budowanie grup w Monitoring API to niepotrzebny narzut operacyjny (toil).
D. Logowanie to analiza zdarzeń (logi), a nie metryk wydajnościowych (CPU/Memory). Analiza logów do badania CPU/RAM jest nieprecyzyjna i bardzo kosztowna (BigQuery).

Analiza i Podsumowanie Dyskusji (AI)

W DevOps: Natywna usługa GCP zawsze wygrywa z narzędziami trzecimi (Prometheus), jeśli zależy Ci na minimalizacji "toil" (pracy operacyjnej). Cloud Monitoring automatycznie zbiera metryki z GKE.
