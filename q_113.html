Question 113 / 201

Monitoring

You are running a web application deployed to a Compute Engine managed instance group. Ops Agent is installed on all instances. You recently noticed suspicious activity from a specific IP address. You need to configure Cloud Monitoring to view the number of requests from that specific IP address with minimal operational overhead.

What should you do?

  • A. Configure the Ops Agent with a logging receiver. Create a logs-based metric.
  • B. Update the application to export the IP address request metrics to the Cloud Monitoring API.
  • C. Configure the Ops Agent with a metrics receiver.
  • D. Create a script to scrape the web server log. Export the IP address request metrics to the Cloud Monitoring API.
Show Suggested Answer
Suggested Answer: A 
Odpowiedź: A

Wyjaśnienie:
Logs-based metrics (metryki oparte na logach) są najskuteczniejszym i najbardziej natywnym sposobem w GCP na przekształcanie danych z logów (np. adresy IP z logów web serwera) w metryki, które można wizualizować w Cloud Monitoring. Ops Agent zbiera logi, a stworzenie takiej metryki pozwala na filtrowanie po konkretnym polu (IP) bez pisania własnych skryptów (minimalizacja operacyjnego nakładu pracy - 'toil').

Wyjaśnienie niepoprawnych odpowiedzi:
- Opcja B: Modyfikacja aplikacji w celu eksportowania metryk wymaga zmian w kodzie, testów i wdrożenia, co jest znacznie bardziej kosztowne operacyjnie niż użycie natywnych Logs-based metrics.
- Opcja C: Ops Agent z metrics receiver zbiera metryki systemowe (CPU, RAM itp.) lub metryki aplikacji z API, ale nie jest przeznaczony do parsowania logów w celu wyciągania z nich liczby żądań z konkretnego IP.
- Opcja D: Pisanie własnego skryptu ("scrapers") zwiększa złożoność utrzymania (tzw. toil), podczas gdy GCP oferuje gotowe narzędzia do obsługi logów.

Więcej informacji:
- Google Cloud: Logs-based metrics
- Google Cloud: Ops Agent

Analiza i Podsumowanie Dyskusji (AI)

Jeśli musisz monitorować dane z logów w GCP, szukaj w opcjach "Logs-based metrics". To najszybsza metoda bez ingerencji w kod aplikacji.

💡 Wskazówki i Triki (Exam Tips)

  • Minimalizacja operacyjnego nakładu pracy (Toil reduction) oznacza wybieranie narzędzi natywnych GCP, a nie pisanie własnych skryptów.
  • Logs-based metrics pozwalają na alertowanie i wykresy na podstawie logów.
