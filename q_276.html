Question 276 / 284

You are using Cloud Build for a CI pipeline that uses containerized builds. Your monitoring data reveals that the builds are taking longer than expected to run. You want to reduce the build times. What should you do?

  • A. Specify a cached image that can be used for subsequent builds.
  • B. Delete the .gcloudignore file in your code directory.
Show Suggested Answer
Suggested Answer: A 
Odpowiedź: A

Wyjaśnienie:
Wykorzystanie cache'owania warstw obrazów Dockerowych w Cloud Build (`--cache-from`) pozwala na ponowne użycie warstw, które nie uległy zmianie, co drastycznie skraca czas budowania (zamiast budować wszystko od zera).

Wyjaśnienie błędnych odpowiedzi:
- B: Usunięcie `.gcloudignore` zwiększy czas przesyłania plików do budowy, ponieważ wszystkie niepotrzebne pliki (w tym `.git`, node_modules) zostaną wysłane do Cloud Build.

Analiza i Podsumowanie Dyskusji (AI)

Build times = Caching (layers/images).

💡 Wskazówki i Triki (Exam Tips)

  • Faster builds = Layer Caching.
