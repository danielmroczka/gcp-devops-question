Question 121 / 201

Monitoring

You want to share a Cloud Monitoring custom dashboard with a partner team.

What should you do?

  • A. Provide the partner team with the dashboard URL to enable the partner team to create a copy of the dashboard.
  • B. Export the metrics to BigQuery. Use Looker Studio to create a dashboard, and share the dashboard with the partner team.
  • C. Copy the Monitoring Query Language (MQL) query from the dashboard, and send the ML query to the partner team.
  • D. Download the JSON definition of the dashboard, and send the JSON file to the partner team.
Show Suggested Answer
Suggested Answer: A 
Odpowiedź: A

Wyjaśnienie:
Najprostszym i zalecanym sposobem udostępniania niestandardowych pulpitów nawigacyjnych (custom dashboards) w Cloud Monitoring jest udostępnienie samego adresu URL. Partnerzy, którzy mają dostęp do projektu (odpowiednie uprawnienia IAM), mogą następnie otworzyć link i wybrać opcję utworzenia własnej kopii ("save a copy") w swoim obszarze roboczym.

Wyjaśnienie niepoprawnych odpowiedzi:
- Opcja B: Eksportowanie wszystkich metryk do BigQuery i tworzenie dashboardów w Looker Studio jest bardzo kosztowne, skomplikowane i niepotrzebne, jeśli wystarczy prosty dashboard w Monitoring.
- Opcja C: MQL (Monitoring Query Language) jest bardzo przydatny do definiowania zapytań, ale nie zawiera definicji wizualnej całego dashboardu (układ, typy wykresów, etykiety).
- Opcja D: Ręczna manipulacja plikami JSON (definicją dashboardu) jest możliwa (przez API), ale jest to metoda znacznie trudniejsza i bardziej podatna na błędy dla użytkownika niż prosty "copy" przez UI.

Analiza i Podsumowanie Dyskusji (AI)

Dla zadań typu "jak najprościej udostępnić coś w GCP" zawsze szukaj natywnej funkcji interfejsu użytkownika (UI).

💡 Wskazówki i Triki (Exam Tips)

  • Zasada: Jeśli GCP ma natywną funkcję udostępniania ("Share" lub "Save a copy"), wybierz ją zamiast eksportów do innych narzędzi (Looker/BQ) czy edycji plików JSON.
